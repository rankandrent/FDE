# Handoff: fde.tkxel.com

Context for a new working session. Read this first, then `docs/design-system.md`.

## What this is
A marketing microsite for tkxel's **Forward Deployed Engineering (FDE)** services, meant for `fde.tkxel.com`.
Goal: promote FDE and generate discovery-call leads. Owner works in Roman Urdu; replies to them in Roman Urdu.

- Live preview: https://fde-6ok.pages.dev (Cloudflare Pages, auto-deploys every push to `main`)
- Repo: `rankandrent/FDE`. The Astro prototype is kept on the `astro-archive` branch. Do not reintroduce Astro or npm build steps; the owner wants **plain HTML**.

## How the site is built
- Plain HTML pages committed to the repo, with `assets/css/styles.css` and `assets/js/main.js`.
- Pages are generated by `tools/build.py` (Python, stdlib only):
  - `tools/content/*.py`: pillar, service, industry, guide and company page content
  - `tools/content/case_studies.py`: real case studies from tkxel.com (results as tkxel.com reports them)
  - `tools/posts/*.json`: blog posts
  - `tools/art.py`: per-page hero illustrations and blog cover SVGs
- `services/agentic-fde-pod/index.html` and `index.html` were hand-made. `build.py` reads the shared header, footer and form blocks from the agentic page and rewrites both hand-made pages.
- Workflow after any change:
  ```
  python3 tools/build.py
  python3 tools/check.py   # links, JSON-LD, unique titles, banned words, post JSON shape, in-text links
  ```
- The build is idempotent: running it twice must produce no diff. Verify with `git diff --stat` after a second run.
- Visual checks: `python3 -m http.server 4321`, then Playwright with
  `executablePath: '/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell'`, at 375 and 1440 widths.

## Design rules
`docs/design-system.md` is the source of truth: tokens, section library (§4), page assembly (§6), voice (§1.2), QA (§8).

Key points:
- Plus Jakarta Sans, with IBM Plex Mono for eyebrows only.
- Sharp corners and accent `#0755E9`.
- Dark sections use `--tk-gradient`; never put two dark sections next to each other.
- Headings in sentence case.

Some colour and spacing tokens in the design system are still placeholders (§2.1, §2.3). Confirm them against the tkxel.com stylesheet.
